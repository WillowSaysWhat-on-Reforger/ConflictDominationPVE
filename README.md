# ConflictDominationPVE

This is Gramps303's Conflict PVE with the FIA spawnpoints disabled so that large communities can play Conflict as a Capture and Advance gamemode. With the spawnpoint disabled, the community will need to organise transport to and from the MOB. 

Building on points is also disabled. This means that a dedicated engineer squad will need to construct the communication tents via the Engineer truck (building truck), which has been modified to offer every thing constructable in-game. THis includes, but not limited to:

* Arsenal
* Helipad
* Both vehicle bays
* Medical tent
 
The Construction truck offers a free-to-build-anywhere gameplay. This allows the constructions of FOBs anywhere on the map. Just construct a custom base and spawn a HQ truck, task a logistics squad with keeping the base full of supply, and you then have a local spawn point with an arsenal, veh bays, and med tent. This prevents long flight times and mortar support.

It also creates a perminent quarter master role that lays out, constructs, maintains, and dismantles FOBs. 

However, this can be exploited when not monitored. Players can build temporary camps outside of spawn points that negate all of the extra gameplay. 

So, it is important to understand that Confict Domination is built for high-trust communities that wish to create a mil-sim environment that need little to no admin or GM attention.
